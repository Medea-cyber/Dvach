# Досье: Двач и Телеграм

Расширение для SillyTavern. Раз в N сообщений (по умолчанию 12) модель читает переписку и ведёт досье на тех, с кем общается {{user}}:

- **Телеграм**: все, кто переписывается с {{user}}.
- **Двач**: только аноны, которые заметно взаимодействуют с {{user}}. Безымянным модель даёт кличку, а по манере письма и приметам узнаёт их в следующих тредах.

Профиль постепенно наполняется: характер, манера письма, отношение к {{user}}, что сейчас в жизни, как меняется, факты, история общения и что он может сделать сам. Досье подаётся в промпт, чтобы эти люди помнили прошлое и вели себя последовательно.

## Установка
Extensions → Install extension → ссылка на репозиторий. Или положи папку `st-board-dossier` в `data/<пользователь>/extensions/`.

## Управление
- 📌 — подавать профиль в промпт всегда
- 🔒 — модель не меняет профиль (правишь только ты)
- 👁 — не подавать в промпт, но хранить
- Карточка раскрывается по нажатию, все поля можно править
- «Что уходит в промпт» показывает текущую вставку
- Хранить досье можно в чате или для карточки, тогда оно общее на все чаты с ней
